# Architecture

The project is split into a Streamlit frontend and placeholder backend packages.

Current Phase 1 scope:

- `app/` contains the runnable Streamlit UI.
- `backend/` contains simple placeholder modules for future voice, service, audio, conversation, and metrics work.
- `tests/` contains basic checks for the current placeholder state.

Realtime voice, interruption detection, cancellation, stale-response prevention, recovery, and latency measurement are not implemented yet.
